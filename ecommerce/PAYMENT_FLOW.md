# Payment & Reservation Flow (test/demo setup)

This build confirms payments **without needing a public webhook URL** — it asks Xendit
"is this paid?" when the buyer returns and while the QR page is open. Perfect for localhost.

## The flow

1. **Cart → Checkout** → click **"Generate QR & Pay"**.
2. `api/payment.php` creates the Xendit invoice and redirects to **`pay.php`**.
3. **`pay.php`** shows:
   - a **scannable QR code** of the Xendit invoice URL, and
   - a **"Pay on Xendit →"** button (opens the hosted checkout).
   - It **polls** `api/payment_status.php` every 4s.
4. When you complete the test payment on Xendit:
   - the page detects it, shows **"✅ Payment complete!"**, and redirects to
     **`order-success.php`** which now reads **"Payment Complete!"**.
5. On confirmation the system automatically:
   - sets the transaction status to **`paid`**,
   - sets each purchased listing to **`reserved`** → it **disappears from public listings**,
   - clears the buyer's cart.

> How confirmation works without a webhook: `syncTransactionWithXendit()` calls Xendit's
> `GET /v2/invoices/{id}` and, if the invoice is `PAID`/`SETTLED`, settles the order locally.
> It runs from `pay.php`, `order-success.php`, and the polling endpoint. The original
> `xendit_webhook.php` still works too if you later add a public URL (e.g. ngrok) — both
> paths are idempotent, so there's no double-processing.

## Admin side

- **Admin → 📦 Reserved tab**: every paid item, with the buyer's name/email/phone and the
  order number. Public visitors can't see these (they're `status='reserved'`).
  - **"Mark as Sold"** button moves an item to `sold` (off the reserved list).
- **Admin → 💼 Sell Inquiries**: once an inquiry is **approved**, it's **removed from the list**
  (it has already become a live listing). New/reviewing/rejected ones still show.

## Notes
- The QR image is generated by a hosted QR service from the invoice URL; it scans reliably and
  needs internet (your site already needs internet to reach Xendit).
- Status colors: `paid/completed`=green, `pending`=amber, `processing`=blue,
  `cancelled`=rose, `expired`=slate.
- Remember to set a **valid Xendit secret key** in `config.local.php` (the diagnostic
  `xendit_test.php` confirms it). Delete `xendit_test.php` before sharing the site.
